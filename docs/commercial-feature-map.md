# Commercial feature map

WorldPrize intentionally models only the part of an instant-win promotion that benefits from World ID.

## Included

- product-code entries
- free daily entry protection
- instant-win random odds
- prize inventory
- audit events
- admin stats
- masked public audit trail

## Not included

- full ePrize replacement
- multi-tenant SaaS
- brand account system
- visual campaign builder
- legal rules generator
- tax forms
- physical fulfillment
- receipt OCR
- email/SMS marketing
- referral system
- real crypto escrow/payout
- onchain randomness

## Pitch

The demo shows how World ID can reduce abuse on the legally required no-purchase path while leaving the purchase path intact.
